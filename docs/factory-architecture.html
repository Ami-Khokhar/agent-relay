Software Factory — Architecture

Two fixed cells (agent-relay as the local execution bus, pr-gatekeeper as the review + merge gate) joined by a durable blackboard and a controller that owns the work item.

Two planes

  • GitHub plane (#3) — durable blackboard and source of truth between phases: issues, PRs, labels, events.
  • agent-relay plane (#4) — ephemeral, local execution bus: dispatch one task, wait, get the result.
  • Phases talk through GitHub; execution happens through the relay.

The loop

  • issue → controller → relay → worker → PR → gate → decision → back to controller.
  • repository_dispatch is a wake-up hint; the periodic reconcile against GitHub is the truth.
  • CHANGES → fresh fix WorkOrder on the same branch. HUMAN → escalation queue.

Trust boundary

  • gates job runs untrusted PR code with no secrets.
  • review job holds secrets and never runs PR code.
  • PR code and credentials never share a runner.

Agnosticism axes

  • Harness-agnostic — enforced at the worker pool; any CLI behind the adapter contract.
  • Model-agnostic — enforced at the Model gateway: logical role → provider profile + model.
  • Both are configuration, not code.
